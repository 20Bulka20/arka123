# АРКА 123

Тестовое задание на позицию вайбкодера: cover-страница с отчётом и готовый
промосайт пространства напротив Национальной библиотеки в Минске.

## Маршруты

- `/` — cover: что сделано, инструменты, время, lookbook, видео, ссылка на сайт
- `/site` — сам сайт АРКА 123

## Статус заданий

1. Анимация логотипа — выполнено
2. Фирменный персонаж — выполнено
3. Помещение в 3D — не выполнялось
4. Герой бренда (видео) — выполнено
5. Готовый сайт — выполнено

## Запуск

Нужен Node.js 22.

```bash
nvm use 22
npm install
npm run prepare:media
npm run dev
```

Production:

```bash
npm run lint
npm run build
npm run start
```

## Инструменты

- ChatGPT — портреты персонажа
- MiniMax Hailuo AI — приветственное видео
- Gemini — промпты и поиск референсов
- Cursor — план, архитектура, frontend, анимации, интеграция

Время: около 20 часов (`data/submission.ts`).

## Стек

Next.js 16, TypeScript, Tailwind CSS 4, Sharp, FFmpeg.
