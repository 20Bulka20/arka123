# АРКА 123

Промосайт пространства для мастер-классов и семинаров напротив Национальной
библиотеки в Минске. Проект закрывает пять частей тестового задания: анимацию
логотипа, фирменного персонажа, объёмную презентацию помещения, видео героя и
готовый адаптивный сайт.

## Запуск

Нужен Node.js 22. Если в терминале другая версия:

```bash
nvm use 22
```

Первый запуск:

```bash
npm install
npm run prepare:media
npm run dev
```

Сайт откроется на http://localhost:3000. Чтобы перезапустить, остановите процесс в терминале через `Ctrl+C` и снова выполните `npm run dev`.

Если порт уже занят, можно поднять на другом:

```bash
npm run dev -- --port 3001
```

Production-проверка:

```bash
npm run lint
npm run build
npm run start
```

## Концепция

- В основе айдентики — арочные окна, графитово-синий цвет и молочный фон.
- Логотип сначала прорисовывает цифру `1` и контур арки, затем открывает полный
  знак. Одна анимация используется в прелоадере и при наведении.
- Фирменная героиня — хозяйка пространства в строгом графитовом костюме с
  брошью `123`. Она встречает посетителя и приглашает пройти в зал.
- Первая прокрутка запускает приветственный ролик. Текстовые сообщения
  переключаются по таймкодам: знакомство → `123 м²` → арочные окна и вид на
  Библиотеку.
- Помещение показано интерактивным фототуром по реальным ракурсам. Архитектура
  не меняется; варианты рассадки накладываются отдельно.

## Материалы

Оригиналы лежат в `media/originals` и не раздаются сайтом. Веб-копии AVIF/WebP — в `public/media`. Каталог ракурсов, роли кадров и замечания аудита — в `data/assets.ts`.

2K-видео подготовлено без звука и с `faststart`. Для
`prefers-reduced-motion` используется статичный постер.

## Технологии

- Next.js 16, App Router
- TypeScript
- Tailwind CSS 4
- Sharp и FFmpeg для подготовки медиа
